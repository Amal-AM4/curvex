# CURVEX - Custom Mousepad Landing Page

![Curvex Demo Banner](./screenshots/curvex.jpg)
![Curvex Demo Banner](./screenshots/cur-mob.jpg)

**Curvex** is a responsive, minimal, and clean landing page built for a **customized mousepad brand**.  
Designed with customer satisfaction in mind, the landing page serves as a first point of contact for showcasing custom mousepad products and services.

---

## Features

- Simple and elegant user interface
- Fully responsive layout (mobile, tablet, desktop)
- HTML5 and CSS3 only (no frameworks or JavaScript)
- Optimized for user engagement and product presentation
- Focused on brand value and customer trust
